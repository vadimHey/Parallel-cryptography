# Parallel Cryptography

Исследование эффективности параллельного шифрования файлов с использованием OpenMP. Сравнение алгоритмов XOR и AES на языке C.

## Требования
Для запуска проекта необходимы следующие компоненты:
* GCC с поддержкой OpenMP
* Библиотека OpenSSL
* ОС Unix

## Makefile

Компиляция исполняемого файла
```bash
    make
```

Запуск тестовой версии программы
```bash
    make test
```

Создание тестовых файлов для эксперимента (1-50 МБ)
```bash
    make generate
```

Удаление каталогов bin, data и results и их содержимого
```bash
    make clean
```
## Эксперимент
Запуск эксперимента шифрования 4 файлов различных размеров двумя симметричными алгоритмами XOR и AES
```bash
    ./script/run_tests.sh
```
