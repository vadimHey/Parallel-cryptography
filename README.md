# Parallel Cryptography

Исследование эффективности параллельного шифрования файлов с использованием OpenMP. Сравнение алгоритмов XOR и AES на языке C

## Требования
Для запуска проекта необходимы следующие компоненты:
* GCC с поддержкой OpenMP
* Библиотека OpenSSL
* ОС Unix

## Makefile

Компиляция исполняемого файла
```bash
make
```

Запуск тестовой версии программы
```bash
make test
```

Создание тестовых файлов для эксперимента (1-50 МБ)
```bash
make generate
```

Удаление каталогов bin, data и results и их содержимого
```bash
make clean
```

## Парсинг аргументов
Программа поддерживает следующие аргументы командной строки:
| Опция	| Описание |
| :--- | :--- |
| `-f` | Входной файл |
| `-a` | Алгоритм (xor или aes) |
| `-p` | Параллельный режим (OpenMP) |
| `-t` | Количество потоков |
| `-c` | Размер чанка в байтах |
| `-m` | Количество замеров |
| `-o` | Выходной CSV-файл |

## Программа
Пример ручного запуска исполняемого файла с краткими версиями аргументов
```bash
# Последовательное шифрование XOR
./bin/crypto_benchmark -f data/50MB.bin -a xor -m 30

# Параллельное шифрование AES на 4 потоках
./bin/crypto_benchmark -f data/50MB.bin -a aes -p -t 4 -c 65536 -m 30
```

## Эксперимент
Запуск полного эксперимента: шифрование файлов различных размеров (1, 5, 10, 25, 50 МБ) двумя симметричными алгоритмами (XOR и AES) с 30 замерами для каждого теста
```bash
./script/run_tests.sh
```
Результаты сохраняются в каталог results/ в формате CSV
